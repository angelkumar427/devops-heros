=== Multi-stage vs single-stage Docker build - size comparison ===
Docker 29.5.2 on aarch64
Date: Thu Sep  3 23:39:37 IST 2026

--- 1. Build the NAIVE single-stage image (ships the whole Go toolchain) ---
$ docker build -f Dockerfile.single-stage -t gohello-singlestage .
Step 6/6 : ENTRYPOINT ["/out/server"]

 ---> 1281f8c3d9de

--- 2. Build the MULTI-STAGE image (scratch + static binary only) ---
$ docker build -f Dockerfile -t gohello-multistage .
Step 8/8 : ENTRYPOINT ["/server"]
 ---> Running in 6603ac316328
 ---> Removed intermediate container 6603ac316328
 ---> cc227adf43ea
Successfully built cc227adf43ea
Successfully tagged gohello-multistage:latest

--- 3. Compare the two image sizes ---
$ docker images | grep gohello
REPOSITORY            TAG             SIZE
gohello-multistage    latest          10.5MB
gohello-singlestage   latest          440MB

single-stage : 440MB on disk (full Go toolchain shipped in the final image)
multi-stage  : 10.5MB on disk (scratch base + one static binary)
reduction    : 42x smaller (440MB -> 10.5MB)

--- 4. Run a container from the multi-stage image on port 8080 ---
$ docker run -d --name gohello -p 8080:8080 gohello-multistage
